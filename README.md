A simple Wayland window manager built on [wlroots 0.20](https://gitlab.freedesktop.org/wlroots/wlroots).

## Features

Window management (focus, move, resize, fullscreen), tiling modes, GNOME-style overview, command box, topbar with clock/network/audio, workspaces, XWayland, desktop notifications, and more.

See [Features](docs/features.md) for the full list.

## Build

```sh
./build.sh
```

Run: `./build/guibuxwm`

Requires the Liberation monospace font, which provides the text face used by the
topbar, command box, overview and every overlay. Without it those are disabled
and you get a black screen. Install it once:

```sh
sudo zypper install liberation-fonts   # /usr/share/fonts/truetype/LiberationMono-Regular.ttf
```

Brightness control (`brightness-up` / `brightness-down` and the
`XF86MonBrightness*` keys) shells out to `brightnessctl`:

```sh
sudo zypper install brightnessctl
```

`brightnessctl` writes `/sys/class/backlight/<dev>/brightness`, which is
`root:root 0644` by default on openSUSE (the device is tagged `seat` but not
`uaccess`), so every set fails with *Permission denied* for a normal user.
Grant the seat user an ACL once:

```sh
echo 'SUBSYSTEM=="backlight", ACTION=="add", TAG+="uaccess"' \
  | sudo tee /etc/udev/rules.d/90-backlight-uaccess.rules
sudo udevadm control --reload && sudo udevadm trigger --subsystem-match=backlight
```

Re-login so logind applies the ACL (`getfacl /sys/class/backlight/*/brightness`
should then list `user:<you>:rw-`).

See [Build](docs/build.md) for requirements.

## Keybindings

`Mod` is the Super key. `Mod+Return` opens terminal, `Mod+e` opens command box, `F12` toggles overview, `Mod+Shift+q` quits.

See [Keybindings](docs/keybindings.md) for the full list.

## Configuration

Config file at `~/.config/guibuxwm/config` (sample in [`config/guibuxwm`](config/guibuxwm)). CLI flags: `-t` terminal, `-k` keyboard layout, `-c` config path.

See [Configuration](docs/config.md) for the full reference.

## Lock Screen

The lock screen (`Mod+Shift+l`) authenticates via PAM. A PAM config file is required — without it PAM falls back to `/etc/pam.d/other` (empty) and every password is rejected.

Install it once (as root):

```sh
sudo cp config/etc/pam.d/guibuxwm /etc/pam.d/guibuxwm
```
